# Gamepass Shop

The HUD Shop showcases every planned gamepass from the Monetization section of `GAME_DESIGN_REQUIREMENTS.md`, plus
the owner's VIP gamepass. The catalogue includes VIP, 2x Auto-Roll, Extra Roll I/II, Speed Doubler I-V, 2x Money,
+1 Luck, +2 Luck, Gold/Diamond/Void Workshop, Ember Wyvern, and Singularity.

The Shop is presentation-only until Creator Dashboard IDs are assigned. Entries with id `0` remain visible as
"Coming soon" and cannot prompt a purchase. Nonzero entries prompt the corresponding Roblox gamepass purchase.
Prices are never stored in the game; Roblox owns the price and ownership record.
