# Market icon sources

Original vector artwork authored for Racer-RNG, 2026-10-20. No third-party assets,
brands, fonts or extracted game artwork. Project-original artwork; no external
license requirements. Each SVG has a transparent canvas and a 100 × 100 viewBox.

The canonical segment recipes are `src/shared/MarketArtConfig.luau`. `MarketArt`
renders the same paths as Roblox UI geometry, so Backpack/Market never depend on
an invented or unapproved upload id. `MarketConfig.Icon` identifies each original
icon. SVG/PNG export tool: `tools/export_market_icons.py`.
